개인정보처리방침

AndWorksPicture(이하 "운영자")가 사내 제작 관리 앱 FLOWCUT을 운영하면서 처리하는 정보와 처리 방식을 안내합니다. 시행일: 2026년 10월 3일

1. 처리하는 정보와 목적

정보목적·보관 위치
FLOWCUT 계정 이메일, 사용자 식별자, 역할·프로젝트 권한로그인과 접근 제어. Supabase 인증·데이터베이스에 저장합니다.
프로젝트·장면·컷 정보, 프롬프트, 작업 상태, 버전·검토 기록, 파일 식별자제작 관리와 협업. Supabase 데이터베이스에 저장합니다.
Google 계정 이메일과 확인 상태회사 Drive를 연결할 때 지정한 계정이 맞는지 확인합니다.
Drive 파일·폴더와 관련 식별 정보제작 자료의 업로드, 다운로드, 폴더 정리와 결과 저장. 파일은 회사 Google Drive에 저장합니다.
Google 연결 유지용 인증 정보회사 Drive 연결을 유지하기 위해 Supabase 서버의 비밀 설정에만 저장합니다. 직원 PC에는 저장하지 않습니다.
연결한 생성 서비스 계정의 인증 정보와 실행 기록사용자가 요청한 생성 작업을 실행하고 상태를 확인합니다. 인증 정보는 서버 전용 저장 영역에서 관리합니다.

2. Google 접근 범위

이메일 확인과 drive.file 범위만 요청합니다. FLOWCUT이 만들었거나 FLOWCUT에서 열도록 허용한 파일을 읽고, 만들고, 수정하거나 삭제할 수 있는 범위이며, Drive의 다른 파일을 읽을 수 있는 권한이 아닙니다. 파일 삭제는 Drive 휴지통으로 이동하는 방식을 사용합니다.

3. 외부 서비스와 제공

정보는 다음 서비스에서 처리됩니다. 운영자는 이 외의 제3자에게 정보를 판매하거나 제공하지 않습니다.

  • Supabase: 로그인, 작업 데이터 저장, 서버 처리
  • Google Drive: 제작 파일 저장
  • Higgsfield, Magnific: 사용자가 이미지·영상 생성을 요청한 경우에 한해, 그 요청의 프롬프트와 참조 자료를 전달합니다.

각 서비스는 해외 서버에서 정보를 처리할 수 있으며, 각 서비스의 개인정보 정책이 함께 적용됩니다. 권한을 받은 팀원은 담당 프로젝트의 자료에 접근할 수 있습니다.

4. Google 사용자 데이터의 사용 제한

Google API로 받은 정보는 사용자가 요청한 파일 관리와 제작 기능에만 사용합니다. 광고, 데이터 판매, 범용 AI 모델 학습에는 사용하지 않습니다. FLOWCUT이 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 보관과 삭제

작업 데이터와 파일은 해당 프로젝트를 운영하는 동안 보관합니다. 프로젝트가 끝나거나 삭제를 요청받으면 운영자가 확인한 뒤 서버 기록과 Drive 파일을 삭제합니다. 법령에 따라 보관해야 하는 정보는 그 기간 동안 보관합니다.

회사 Drive 계정 소유자는 Google 계정의 연결된 앱에서 언제든 FLOWCUT의 접근을 철회할 수 있습니다. 철회하면 이후 접근이 중단되며, 이미 저장된 자료는 자동으로 삭제되지 않습니다.
